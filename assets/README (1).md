# Изображения

Сейчас в `assets/images/` лежат простые заглушки, чтобы сайт открывался и ничего не было
битым. Замени их реальными файлами — **важно сохранить ровно эти имена**, тогда в
`index.html` ничего менять не придётся:

| Файл | Что туда положить | Ориентировочный размер |
|---|---|---|
| `anna-photo.jpg` | твоё фото из hero-блока (то, что в Figma) | ~640×760, портретная ориентация |
| `koyash-screenshot.jpg` | скриншот интерфейса Koyash | ~900×600 |
| `blobbi-screenshot.jpg` | скриншот интерфейса Blobbi | ~900×600 |

## Откуда взять оригиналы

- Фото и скриншоты — экспортируй прямо из Figma: выдели картинку → правая панель →
  Export → PNG/JPG.
- Или возьми свежие скриншоты самих задеплоенных сервисов (Koyash и Blobbi уже
  работают — можно проскриншотить актуальный интерфейс).

## Декоративные элементы

Голубой "блоб" за фото в hero-блоке сейчас сделан на чистом CSS (`.hero-blob` в
`style.css`) — органическая форма похожей формы, но не одна в один с рукописным
вектором из Figma (те эккзкортировать напрямую не получилось — сетевые ограничения
среды, в которой я работаю, не пускают на серверы Figma). Если хочешь точную форму —
экспортируй нужный вектор из Figma как SVG и подставь вместо `.hero-blob`.
